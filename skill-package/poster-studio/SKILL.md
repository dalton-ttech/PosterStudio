# Poster Studio

Use a reference-first workflow.

1. If the task needs visual research, read `references/research.md`.
2. If the user provides selected reference images, read `references/generation.md`.
3. Keep image prompts concise. Do not convert reference images into long art-direction prompts.
4. Use one isolated generation context per reference. Keep mimic and inspired comparisons isolated.
5. First-pass generation should include the real copy so typography and imagery are designed together.
6. For revisions, distinguish clean regeneration from editing an accepted image.
7. Use deterministic typography/logo repair only when exact content cannot be fixed reliably by image editing.

Never require a global AGENTS.md. Never automatically ingest unselected Pinterest imagery.
