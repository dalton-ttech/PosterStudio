# Finishing

First pass includes full real copy.

Repair order:
1. keep correct text
2. use image edit for small copy errors
3. if exact copy remains unreliable, preserve the model's layout and repair typography deterministically
4. replace any altered/generated brand logo with the supplied original source asset

Do not impose pre-generation contrast/mask rules unless the user specifically asks for them.

HTML is for review or explicit HTML editing requests, not the default final-poster renderer.
