# Start Here

Open this repository in Codex Desktop.

For a new poster task, say:

> Read WORKFLOW.md and start a new poster project.

Recommended local directories:

- `private/brands/` — logos, VI files, brand assets, fixed brand information.
- `private/library/inbox/` — Pinterest images that **you have already selected**.
- `private/library/references/` — organized reference library.
- `private/projects/` — active poster projects and generated images.

These directories are intentionally gitignored.

Do not load unrelated docs. `WORKFLOW.md` points to detailed files only when that phase is active.
