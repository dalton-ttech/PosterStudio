# Reference Library

The library contains **human-selected** visual references only.

## Local flow

`private/library/inbox/`
→ user-selected downloads awaiting organization

`private/library/references/`
→ organized reference assets

`private/library/manifest.json`
→ searchable metadata

## Naming

`<PROJECT>-R<NNN>-S<NN>.<ext>`

Example:
`ZQJ-R001-S01.jpg`

- `ZQJ`: project / occasion code
- `R001`: reference number
- `S01`: optional style-family number

Do not infer that a downloaded Pinterest image is approved by the model. Human download/selection is the approval gate.

Metadata can describe the image for retrieval, but those tags should not automatically be expanded into the image prompt.
