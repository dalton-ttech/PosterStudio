# Brief

Keep briefs compact.

Recommended fields:
- project code
- brand
- occasion / use case
- target surface
- aspect ratio (default 9:16 for mobile posters)
- exact copy
- supplied assets
- must-keep constraints
- optional title requirement
- selected reference IDs
- generation mode: mimic / inspired

Do not add speculative art-direction language unless the user explicitly requested it.

If a title must be proposed, develop a small set that reflects the specific brand and occasion rather than generic festival copy.
