# Privacy and Assets

The public repository stores workflow logic, templates, and scripts only.

Keep these local by default:
- brand logos and VI source files
- company/client addresses and private copy if sensitive
- Pinterest reference images
- generated outputs
- client photography
- licensed fonts
- source PSD/AI files

Recommended local paths:
- `private/brands/`
- `private/library/`
- `private/projects/`

The repository `.gitignore` excludes these paths.

Never commit font files to this repository.
